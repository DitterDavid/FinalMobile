# Proyecto 18 · Registro de vehículo

Este espacio contiene únicamente el proyecto 18 del ZIP recibido: una app móvil para controlar vehículos, tanqueos, mantenimientos y viajes. La especificación original quedó resumida en los README de cada repositorio; los demás proyectos del ZIP se descartaron.

## Repositorios

- `18-registro-de-vehiculo-app`: Expo, React Native, TypeScript y SQLite local.
- `18-registro-de-vehiculo-api`: Next.js Route Handlers y Firebase Admin del lado servidor.

Abre esta carpeta en Visual Studio Code. No agregues claves ni archivos `.env` al control de versiones.
